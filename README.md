# VaviVPN для Android — выпуски

Здесь лежат установочные файлы приложения VaviVPN для Android и файл `version.json`, по которому приложение узнаёт о новой версии.

## Какой файл скачать

В разделе [Releases](https://github.com/muodosta/vavivpn-releases/releases/latest):

- `vavivpn-<версия>-arm64-v8a.apk` — для большинства телефонов;
- `vavivpn-<версия>-armeabi-v7a.apk` — для старых 32-битных телефонов.

Нужен Android 7.0 или новее. Контрольные суммы — в `SHA256SUMS.txt`.

## Обновления

Приложение само проверяет новую версию. `version.json` подписан ключом VaviVPN: приложение устанавливает файл, только если подпись, контрольная сумма и подпись APK совпадают.
