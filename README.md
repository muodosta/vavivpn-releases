# VaviVPN — выпуски приложений

Установочные файлы приложений VaviVPN и манифесты, по которым приложения узнают о новых версиях. Репозиторий общий для всех платформ.

## Скачать

Откройте [Releases](https://github.com/muodosta/vavivpn-releases/releases) и выберите выпуск своей платформы.

**Android** — выпуски `android-v<версия>`, Android 7.0 или новее:
- `vavivpn-android-<версия>-arm64-v8a.apk` — для большинства телефонов;
- `vavivpn-android-<версия>-armeabi-v7a.apk` — для старых 32-битных телефонов.

Контрольные суммы — в `SHA256SUMS.txt` каждого выпуска.

## Как устроен репозиторий

| Что | Имя | Пример |
|---|---|---|
| Выпуск версии | тег `<платформа>-v<версия>` | `android-v0.1.1`, `windows-v1.0.0` |
| Файлы версии | `vavivpn-<платформа>-<версия>-<вариант>.<расширение>` | `vavivpn-android-0.1.1-arm64-v8a.apk` |
| Манифесты обновлений | выпуск с тегом `channels`, файлы `<платформа>-<канал>.json` | `android-stable.json`, `windows-stable.json` |

- Приложение читает свой манифест по постоянному адресу: `https://github.com/muodosta/vavivpn-releases/releases/download/channels/<платформа>-<канал>.json`. Адрес `latest` не используется.
- Сборка каждой платформы публикует свой выпуск версии и затем перезаписывает только свои манифесты в `channels`.
- Манифест подписан ключом VaviVPN (Ed25519) и содержит название платформы. Приложение ставит обновление, только если подпись, платформа, контрольная сумма и подпись установочного файла совпадают.
